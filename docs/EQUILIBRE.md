# Indice d'équilibre

Indice **maison et indicatif**, de A (très équilibré) à E (à limiter). Ce
n'est **pas** un Nutri-Score et il n'a **aucune valeur médicale**.

## Calcul

1. Chaque ingrédient est pesé (grammes ; volumes convertis par la densité
   du produit, pièces par leur poids). Les recettes composées sont déroulées.
2. Les ingrédients facultatifs, et les groupes neutres (épices et
   condiments, boissons de cuisson, produits non classés), ne comptent pas.
3. Pour chaque groupe alimentaire : **points = coefficient × part du poids
   (en %)**. Le score est la somme.
4. La lettre dépend du score : A ≥ 35, B ≥ 15, C ≥ −5, D ≥ −25, sinon E.

## Grille par défaut

| Groupe | Coefficient |
|---|---|
| Légumes | +1 |
| Légumineuses | +1 |
| Fruits | +0,8 |
| Poisson et fruits de mer | +0,8 |
| Féculents complets | +0,6 |
| Volaille | +0,3 |
| Œufs | +0,3 |
| Fruits à coque et graines | +0,3 |
| Produits laitiers | +0,2 |
| Féculents raffinés | 0 |
| Fromages | −0,3 |
| Viande rouge et porc | −0,5 |
| Plats transformés | −0,8 |
| Charcuterie | −1 |
| Produits sucrés | −1,2 |
| Matières grasses ajoutées | −1,5 |

Exemple : une ratatouille (95 % de légumes, 4 % d'huile) obtient
+95 − 6 = 89 points, soit A ; un fondant au chocolat (sucre, beurre,
chocolat) obtient E.

## Transparence et réglages
- La fiche de chaque recette affiche la contribution de chaque groupe
  (« Légumes : 62 % du poids, +62 points ») et les ingrédients dont le poids
  est inconnu.
- La grille (coefficients et seuils) se règle dans **Paramètres > Grille de
  l'indice d'équilibre** ; toutes les recettes sont recalculées.
- Une recette peut être **ajustée à la main** (mention affichée).
- Si tous les ingrédients pesés ont leurs valeurs nutritionnelles, une
  estimation par portion (énergie, protéines, glucides, lipides, fibres) est
  affichée en plus, signalée comme estimation.
